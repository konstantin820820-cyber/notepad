# 📱 Мой Локальный Блокнот (Xiaomi x Google Keep Style) (beta)

Полностью автономное, быстрое и конфиденциальное мобильное приложение-блокнот для Android, созданное с помощью нейросети на фреймворке Flutter.

## ✨ Основные возможности
*   **Сортировка по вкладкам:** Заметки распределяются по категориям (*Личное, Работа, Идеи, Покупки*).
*   **Управление разделами:** Через кнопку ⚙️ (Шестерёнка) на главном экране можно добавлять новые темы или удалять старые.
*   **Перетаскивание жестами:** Свободное изменение порядка плиток на главном экране — зажмите заметку пальцем и перетащите её на новое место.
*   **Текстовый движок Fleather:** Полноценный визуальный редактор с физическим форматированием текста (Жирный, Курсив) и умными интерактивными списками (включая чек-боксы с галочками).
*   **100% Локальность:** Приложение работает без интернета, не собирает аналитику, не показывает рекламу и хранит данные строго в памяти телефона через `shared_preferences`.

## 🛠️ Как скачать и установить готовый APK
Вам не нужно настраивать окружение или устанавливать программы для разработки. Робот GitHub Actions собирает приложение автоматически.

1. Перейдите в верхнем меню репозитория во вкладку **Actions**.
2. В списке сборок выберите самую верхнюю (последнюю) с **зелёной галочкой**.
3. Прокрутите страницу в самый низ до раздела **Artifacts** (Артефакты).
4. Нажмите на ссылку **`release-apk`** и скачайте архив.
5. Распакуйте архив на телефоне (внутри будет файл `.apk`).
6. Удалите старую версию блокнота с телефона (если она была установлена).
7. Запустите `.apk` файл и подтвердите установку из неизвестных источников.

## 🗂️ Структура проекта в папке `lib/`
*   `main.dart` — точка входа, инициализация базы данных, вкладок и логика главного экрана.
*   `editor.dart` — экран написания заметки, интеграция визуального редактора и панели инструментов.
*   `note.dart` — модель данных заметки с логикой перевода в формат хранения JSON.
*   `grid_view.dart` — сетка плиток с логикой перетаскивания элементов жестами.
 Блокнот создан с использованием ИИ. Это beta-версия, возможны ошибки и баги.
