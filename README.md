# 📱 Мой Локальный Блокнот

Автономный блокнот для Android, созданный на Flutter.

Приложение предназначено для быстрого создания и хранения обычных текстовых заметок непосредственно на устройстве.

## ✨ Возможности

- 📝 Создание и редактирование заметок
- 💾 Автоматическое сохранение заметок внутри приложения
- 📄 Хранение текста без привязки к облачным сервисам
- 📂 Разделение заметок по категориям
- ➕ Создание собственных разделов
- ✏️ Переименование разделов
- 🗑️ Удаление разделов
- 🔄 Изменение порядка разделов
- 🔀 Изменение порядка заметок перетаскиванием
- 🗑️ Корзина для удалённых заметок
- ♻️ Возможность восстановить случайно удалённую заметку
- 📤 Сохранение заметки на устройство в формате `.txt`
- 📑 При сохранении в TXT сохраняется обычный текст с переносами строк, пробелами и отступами
- 🌙 Тёмный интерфейс
- 📱 Оптимизировано для использования на Android
- 🔒 Работа без обязательного подключения к интернету

## 🗂️ Хранение заметок

Приложение не использует облачную базу данных.

Основные данные заметок хранятся локально на устройстве.

Внутри приложения используется обычный текст заметки. Форматирование редактора не превращается в отдельный файл Markdown или JSON для экспорта.

При экспорте пользователь получает обычный текстовый файл
